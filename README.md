## Study Tips

- Think first. Spend 20–30 minutes on a problem before looking at hints.
- Brute force, then optimize. Always start with the simplest correct solution.
- Say the complexity out loud. Time and space, every time.
- Revisit. Re-solve problems after a week to check retention.
- Write notes. Record what tripped me up, not just the final answer.
